# รายงานตรวจตารางฐานข้อมูล — 2026-10-22

ตรวจ PostgreSQL schema `public` ที่เชื่อมต่อจากโปรเจกต์แบบอ่านอย่างเดียว ตรวจจำนวนแถวและค้นชื่อ table ใน PHP, JavaScript, HTML และ CSS ของแอป โดยไม่อ่านหรือส่งออกข้อมูลรายบุคคล

## สรุป

- ก่อน cleanup พบ **26 ตาราง** ในฐานข้อมูล
- ตารางอื่น **25 ตาราง** มีการใช้งานใน flow ของระบบ เช่น อ่าน/เพิ่ม/แก้ไขข้อมูล หรือรายงาน
- `exam_logs` มี **3 แถว** ไม่มีการอ่านหรือเพิ่มข้อมูลจาก flow ปัจจุบันใน source ที่ตรวจพบ และไม่มี foreign key จากตารางอื่นอ้างถึง
- ผู้ใช้ยืนยันให้นำ `exam_logs` ออกแล้ว; migration ลบตารางและโค้ด cleanup ที่เหลือถูกนำออกจากระบบ
- ตารางเก่า 5 ตารางที่ระบุใน migration `20261022_remove_unused_legacy_tables.sql` ไม่ปรากฏใน schema ปัจจุบันแล้ว

## ตารางเดิมที่ถูกนำออกแล้ว

`activity_logs`, `course_assignments`, `course_announcements`, `learning_events` และ `video_watch_sessions` ถูกนำออกตาม migration cleanup ก่อนหน้า หลังตรวจว่าไม่มีข้อมูลหรือไม่มี flow ใช้งานตามรายงาน [database cleanup](database_cleanup_20261022.md)

## ข้อเสนอ

หลังลบ `exam_logs` เหลือ 25 ตารางที่ใช้งานอยู่ ตาราง `exam_logs` เดิมมี 3 แถวซึ่งถูกทิ้งตามคำขอของผู้ใช้; migration ใช้ `RESTRICT` เพื่อไม่ให้ลบตารางหากมี foreign key ที่ไม่คาดไว้
